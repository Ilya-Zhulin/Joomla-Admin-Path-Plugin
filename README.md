# Joomla Admin Path Plugin

Плагин предназначен для защиты админпанели Joomla, путём добавления к адресу секретного параметра. Без этого параметра
пользователь будет перенаправлен на главную страницу, страницу 404 или любой другой адрес по Вашему выбору. Параметр
работает столько, сколько живёт сессия пользователя.
Плагин не ведёт никаких логов и не использует БД. Его задача - **защита от подбора пароля**.

## Использование плагина

Плагин активируется автоматически при установке, но, по-умолчанию, не блокирует админку, пока не настроен секретный
параметр.
<img width="910" height="501" alt="image" src="https://github.com/user-attachments/assets/561b6ca9-5af6-45fc-971a-c5f7676ce6a6" />

Для того, чтобы плагин заработал, нужно ввести необходимый Вам **секретный параметр** или оставить предложенный
по-умолчанию. Ниже вы увидите ссылку, по которой будет доступна админ-панель после активации блокировки. Эту ссылку
можно скопировать в буфер обмена. Также, необходимо перейти по ней, нажав на саму ссылку, для предотвращения блокировки
после сохранения параметров плагина.

Если пользователь перейдёт по прямой ссылке на админ-панель или введёт неверный параметр, то его перенаправит на адрес,
который настраивается в поле **Тип перенаправления**. Вы можете выбрать страницу 404, главную страницу сайта, а также
ввести свой адрес для перенаправления.

После окончания всех настроек выберите "Да" в пункте **Блокировать прямой доступ**. При выборе этого пункта активируется
проверка наличия маркера в сессии, который позволяет работать в админке после входа по адресу с секретным параметром.
Если такого маркера нет, то выводится соответствующее предупреждение
<img width="887" height="99" alt="image" src="https://github.com/user-attachments/assets/4956353a-f825-4d65-a651-19fe890bbeb2" />

Необходимо перейти по получившейся ссылке, чтобы установить этот маркер. Как только маркер установится, предупреждение
пропадёт и можно будет сохранять параметры плагина, не боясь быть заблокированным.

## Белый список IP

Если сессия сбрасывается (например, по таймауту), приходится снова входить по ссылке с секретным параметром. Чтобы этого
избежать, в настройках плагина есть поле **Белый список IP**: введите свой IP-адрес (или несколько, по одному на строку
или через запятую) — для этих адресов админка будет работать как обычно, без секретного параметра и без редиректа.

Если включена опция **Напоминать о добавлении IP**, то при повторном входе в админку (в той же сессии браузера) будет
показано системное сообщение с текущим IP и ссылкой на настройки плагина, где IP будет автоматически подставлен в поле
белого списка — останется только сохранить настройки. Напоминание не показывается при первом входе и не показывается,
если IP уже есть в белом списке.
